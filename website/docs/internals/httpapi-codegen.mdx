opencode 是**契约驱动**的：一份 HttpApi 契约，生成多套客户端，喂给多端。这章拆解从契约定义到生成产物的完整链路。

## 链路总览

```
┌─────────────────────────────────────────────────────────────┐
│  契约定义                                                    │
│  packages/protocol/src/api.ts  makeDefaultApi()             │
│    组合 14 个 HttpApiGroup:                                  │
│    message/model/provider/session/permission/fs/command/     │
│    skill/event/agent/health/pty/question/reference/location │
└──────────────────────────┬──────────────────────────────────┘
                           │
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
   server 实现        openapi.json      httpapi-codegen（生成器）
   packages/server    (OpenAPI 规范)    packages/httpapi-codegen
   src/api.ts                            │
   注入 Location 中间件                  │ 读取契约 IR
                                         ▼
                          ┌──────────────────────────────┐
                          │  生成产物（勿手改）            │
                          │  packages/client/src/         │
                          │    generated/      Promise    │
                          │    generated-effect/ Effect   │
                          └──────────────────────────────┘
```

## 契约定义

`packages/protocol/src/api.ts` 的 `makeDefaultApi()`：

- 组合 14 个 HttpApiGroup（message/model/provider/session/permission/fs/command/skill/event/agent/health/pty/question/reference/location）
- 含 `Authorization` / `SchemaError` 中间件
- 这是**唯一**权威契约

`protocol` 仅依赖 `schema`，是依赖图最底层。

## server 实现

`packages/server/src/api.ts`：

- 引用 `makeDefaultApi`
- 注入 `Location` / `SessionLocation` 中间件
- 把契约变成可执行的路由 + handler

实例级组合在 `packages/opencode/src/server/routes/instance/httpapi/api.ts`：

- `RootHttpApi`（`:54`）= Control + ControlPlane + Global
- `InstanceHttpApi`（`:61`）= Config / File / Instance / MCP / Permission / Project / Provider / Pty / Question / Session / Sync / Tui / Workspace 等 21 个 group

handler 在 `handlers/`，中间件在 `middleware/`（9 个：authorization/compression/cors-vary/error/fence/instance-context/proxy/schema-error/workspace-routing）。

## OpenAPI 规范

HttpApi 契约同时产出 OpenAPI 规范：

- `packages/docs/openapi.json` → 软链到 `../sdk/openapi.json`
- 供 Mintlify 文档站（`docs.json` 里 `openapi: https://opencode.ai/openapi.json`）展示 SDK 参考
- 改了契约，OpenAPI 自动跟上，文档站自动更新

## 生成器：httpapi-codegen

`packages/httpapi-codegen`（仅依赖 `effect` + `prettier`）：

- 在 dev 时读取 `protocol` + `server` 的 HttpApi 契约
- 编译成 **SDK Contract IR**（运行时中性的中间表示，保留编/解码类型投影 + 传输元数据）
- 由不同 emitter 产出不同风格客户端

> **SDK Contract IR** 是 `CONTEXT.md` 的规范词：让独立 SDK emitter 自选公开值模型与运行时解释器，而不必每个 SDK 都重新解析契约。

## 生成产物

`packages/client/`：

| 目录 | 风格 | 内容 |
|---|---|---|
| `src/generated/` | Promise 客户端 | `index.ts` / `client.ts` / `types.ts` / `client-error.ts` + `.httpapi-codegen.json` |
| `src/generated-effect/` | Effect 客户端 | `index.ts` / `client.ts` / `client-error.ts` + `.httpapi-codegen.json` |

`.httpapi-codegen.json` 是生成器的元信息（版本、配置）。

## 生成入口与校验

`packages/client/package.json`：

```jsonc
{
  "scripts": {
    "generate": "bun run script/build.ts",
    "check:generated": "bun run generate && git diff --exit-code -- src/generated src/generated-effect"
  }
}
```

- 改了 Protocol/Server HttpApi → 跑 `bun run generate`
- CI 用 `check:generated` 校验生成物是否最新（`git diff --exit-code` 不通过则挂）
- 生成物**不要手改**

## 客户端运行时依赖

`packages/client/package.json`：

- **dependencies**：`@opencode-ai/schema` + `@opencode-ai/protocol`（仅此两个）
- **devDependencies**：`@opencode-ai/core` + `@opencode-ai/server` + `@opencode-ai/httpapi-codegen`（仅生成时用）

运行时 client 与 core/server 彻底解耦——这就是分层约束的落地。详见 [dependency-layering](./dependency-layering)。

## 测试

`packages/opencode/package.json`：

```jsonc
{
  "scripts": {
    "test:httpapi": "bun run script/httpapi-exercise.ts --mode coverage --fail-on-missing --fail-on-skip && ... --mode auth ... && ... --mode effect ..."
  }
}
```

`test:httpapi` 跑三模式（coverage / auth / effect）确保公开 HttpApi 都被覆盖、鉴权与 Effect 模式都正常。新增端点后应跑这个。

## 完整工作流：加一个 HttpApi 端点

```
1. packages/protocol/src/api.ts 的某 group 加 endpoint 声明
2. packages/opencode/src/server/routes/instance/httpapi/handlers/ 加 handler
3. cd packages/client && bun run generate       ← 重新生成客户端
4. cd packages/opencode && bun run test:httpapi  ← 三模式测试
5. bun run check:generated                       ← 确认生成物已更新
6. 提交：契约 + handler + 生成物 一起进 commit
```
